# FioreAir

**Expert Cooling, Trusted Brands**

FioreAir is a trusted provider of premium air conditioning solutions based in Naic, Cavite, serving Metro Manila and the surrounding areas.

## Partner Brands
- Gree
- AUX
- Daikin
- Midea
- Haier

## Aircon Types
- Split-Type
- Window-Type
- Cassette
- Floor-Mounted
- Ducted

## Tech Stack
- [Vite](https://vitejs.dev/) — Build tool
- Vanilla JS — Components
- CSS Custom Properties — Design system
- GitHub Pages — Hosting

## Development
```bash
npm install
npm run dev     # Dev server at localhost:3000
npm run build   # Production build → dist/
npm run preview # Preview built site
```

## Content Management
To add products, edit `src/data/aircon/models/catalog.json`. To add brands, edit `src/data/aircon/brands.json`. Run `npm run build` to regenerate.
